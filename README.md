# Kokedera Icons

*A file icon theme for [JetBrains IDEs](https://www.jetbrains.com), drawn from the quiet green of a moss temple garden.*

> **[kokedera.style](https://kokedera.style)** — visit the website for a full visual walkthrough of the palette, syntax highlighting, and icons.

---

## About

**Kokedera Icons** is a file icon theme for JetBrains IDEs, designed to pair with the [Kokedera color theme](https://plugins.jetbrains.com/plugin/30629-kokedera-moss-temple-theme). Every icon draws from the same palette of moss greens, lantern ambers, and stone grays.

- **File & folder icons** covering languages, frameworks, configs, DevOps, docs, and media
- **Named folder icons** (src, lib, tests, components, api, database, docker, and more)
- **Hundreds of file name & extension mappings** — from `.rs` to `.prisma` to `kustomization.yaml`

## Installation

1. Open your JetBrains IDE (IntelliJ IDEA, WebStorm, PyCharm, GoLand, etc.)
2. Go to **Settings** → **Plugins** → **Marketplace**
3. Search for **"Kokedera Icons"**
4. Click **Install** and restart the IDE

## Compatibility

IntelliJ IDEA 2023.3+ and all JetBrains IDEs based on the IntelliJ Platform.

## Pair with the color theme

For the full experience, install the matching color theme:

- **[Kokedera Theme](https://plugins.jetbrains.com/plugin/30629-kokedera-moss-temple-theme)**
